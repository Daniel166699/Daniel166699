## Featured project

### Interaction Easy Q&A Text and Next-Day Stock Return Prediction

A reproducible rolling-window baseline using Qwen3-Embedding-4B, 1024-dimensional text representations, and eight machine-learning models.

- 4.7M question-time panel events
- 156 out-of-sample monthly windows
- Lasso, Ridge, ElasticNet, RandomForest, XGBoost, LightGBM, CatBoost, MLP
- Strict train-only scaling and chronological evaluation

[Repository](https://github.com/Daniel166699/interaction-easy-return-prediction) · [Project page](https://daniel166699.github.io/interaction-easy-return-prediction/)
